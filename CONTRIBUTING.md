# Contributing

Thanks for helping! This project is intentionally small: **one Python file, no extra packages.**

1. Fork the repo and create a branch: `git checkout -b my-change`
2. Make your change in `server.py` (keep it standard-library only).
3. Test it by running `python server.py --directory <some folder>` and trying folders, video playback, seeking, and downloads.
4. Open a Pull Request and describe what you changed and why.

Ideas welcome: search box, thumbnails, subtitles, HTTPS support, Linux/macOS launcher.
